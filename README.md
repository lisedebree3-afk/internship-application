# Academic Projects – Economics, Data Analysis and Econometrics

This repository presents selected academic research projects completed during my Master's studies in Development Economics at the University of Clermont Auvergne.

The projects focus on economic and policy-related questions and involve quantitative data analysis, statistical programming and econometric methods.

## Projects

### COVID-19 & Airline Financing

**Programming:** R
**Field:** Corporate Finance

This project examines how the COVID-19 crisis affected financing strategies in the US airline industry between 2018 and 2023.

The analysis uses financial data from 55 airline companies and examines changes in equity issuance, debt financing and dividend policies.

**Methods and skills:**

* Data import and preparation
* Data transformation and cleaning
* Regression analysis
* Financial data analysis
* Statistical programming in R
* Automated regression tables and output

### Climate Change & French Viticulture

**Programming:** Stata
**Field:** Environmental and Agricultural Economics

This project examines the relationship between climate conditions and wine production in Bourgogne-Franche-Comté and Nouvelle-Aquitaine between 1994 and 2023.

The analysis combines climate and wine production data and examines annual and seasonal relationships.

**Methods and skills:**

* Data collection and cleaning
* Data aggregation and merging
* Variable creation
* Regression analysis
* Data visualisation
* Statistical programming in Stata

### Electric Vehicles: China & France

**Programming:** R
**Field:** Chinese Economy / Comparative Economics

This project examines factors associated with electric vehicle adoption in China and France between 2015 and 2023.

The analysis considers government subsidies, GDP per capita and charging infrastructure as potential factors associated with EV market share.

**Methods and skills:**

* Data preparation and cleaning
* Data visualisation with ggplot2
* Descriptive statistics
* OLS regression
* Regression visualisation
* Statistical programming in R
